# honours

As part of my BIOM6100 Honours Project, benchmarking of five representative scCNV tools was done as listed below.
- Infercnv
- CopyKAT 
- SCEVAN
- Numbat 
- CopyVAE 

The excuetion scripts used as part of my Honours Project for each tools is available in their reszpective sub-folders.

Thus, this project build upon the original work found in GitHub repositories listed below.

- Infercnv (https://github.com/broadinstitute/infercnv)
- CopyKAT (https://github.com/navinlabcode/copykat)
- SCEVAN (https://github.com/AntonioDeFalco/SCEVAN)
- Numbat (https://github.com/kharchenkolab/numbat)
- CopyVAE (https://github.com/mandichen/copyVAE)
